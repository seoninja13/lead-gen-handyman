# Enriched Data Format Documentation

## Overview

This document provides comprehensive documentation for the enriched data format used in the Handyman Services project. The enriched data is generated by the OpenRouter MCP server and stored in the Supabase database, providing detailed information about handyman service providers.

## Database Storage

The enriched data is stored in the Supabase database with the following specifications:

- **Table**: `businesses`
- **Column**: `enriched_data`
- **Format**: JSONB (JSON Binary)
- **Foreign Key**: The `user_id` column in the `businesses` table is a foreign key to the `id` column in the `users` table

## Data Sections

### 1. Review Insights
Contains information extracted from online reviews and customer feedback:
- **summary**: A concise overview of the general sentiment and key points from reviews
- **strengths**: List of positive aspects frequently mentioned in reviews
- **areasForImprovement**: List of potential weaknesses or areas where the business could improve
- **testimonialHighlights**: Notable quotes or paraphrased feedback from customers

### 2. Service Details
Information about the services offered by the business:
- **certifications**: Professional certifications and credentials held by the business
- **primaryServices**: Detailed information about main services, including:
  - name: Service name
  - description: Detailed explanation of the service
  - estimatedCost: Price range or estimate for the service
- **specializations**: Areas of expertise or specialized services

### 3. Remediation Process
Details about the process used for remediation services:
- **removalPhase**: Information about the removal phase of remediation
- **testingPhase**: Information about the testing phase of remediation
- **assessmentPhase**: Information about the assessment phase of remediation
- **preventionPhase**: Information about the prevention phase of remediation
- **containmentPhase**: Information about the containment phase of remediation

Each phase includes:
- **steps**: List of specific steps taken during this phase
- **description**: Brief summary of the phase's purpose

### 4. Restoration Techniques
Information about techniques and equipment used for restoration:
- **dryingTechniques**: Methods used for drying affected areas
- **specializedEquipment**: Specialized tools and equipment used
- **moistureDetectionTools**: Tools used to detect moisture
- **waterExtractionMethods**: Methods used to extract water

## Implementation Notes

1. The enriched data is generated by the OpenRouter MCP server using the following models:
   - Primary model: google/gemini-2.0-flash-001
   - Fallback model: google/gemini-2.0-flash-001

2. The data is stored in the Supabase database in the businesses table's enriched_data column.

3. The user_id column in the businesses table is a foreign key to the users table and cannot be null.

4. The enriched data is used to enhance business listings with detailed information that improves the user experience and provides valuable insights to potential customers.

## Usage Examples

### JavaScript Example

```javascript
// Example of retrieving and using enriched data in a JavaScript application
async function getBusinessEnrichedData(businessName) {
  try {
    const { data, error } = await supabase
      .from('businesses')
      .select('enriched_data')
      .eq('business_name', businessName)
      .limit(1);

    if (error) {
      throw error;
    }

    if (!data || data.length === 0) {
      throw new Error(`No data found for ${businessName}`);
    }

    return data[0].enriched_data;
  } catch (error) {
    console.error('Error retrieving enriched data:', error);
    throw error;
  }
}

// Usage
getBusinessEnrichedData('Sacramento Handyman Services')
  .then(enrichedData => {
    console.log('Review Insights:', enrichedData.reviewInsights.summary);
    console.log('Strengths:');
    enrichedData.reviewInsights.strengths.forEach(strength => {
      console.log(`- ${strength}`);
    });

    console.log('\nPrimary Services:');
    enrichedData.serviceDetails.primaryServices.forEach(service => {
      console.log(`- ${service.name}: ${service.description}`);
      console.log(`  Estimated Cost: ${service.estimatedCost}`);
    });
  })
  .catch(error => {
    console.error('Failed to get enriched data:', error);
  });
```

### React Component Example

```jsx
import React, { useState, useEffect } from 'react';
import { supabase } from '../lib/supabaseClient';

function BusinessDetails({ businessName }) {
  const [enrichedData, setEnrichedData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    async function fetchEnrichedData() {
      try {
        const { data, error } = await supabase
          .from('businesses')
          .select('enriched_data')
          .eq('business_name', businessName)
          .limit(1);

        if (error) {
          throw error;
        }

        if (!data || data.length === 0) {
          throw new Error(`No data found for ${businessName}`);
        }

        setEnrichedData(data[0].enriched_data);
      } catch (error) {
        console.error('Error fetching enriched data:', error);
        setError(error.message);
      } finally {
        setLoading(false);
      }
    }

    fetchEnrichedData();
  }, [businessName]);

  if (loading) return <div>Loading business details...</div>;
  if (error) return <div>Error: {error}</div>;
  if (!enrichedData) return <div>No enriched data available</div>;

  return (
    <div className="business-details">
      <h2>{businessName}</h2>

      <section className="review-insights">
        <h3>Review Insights</h3>
        <p>{enrichedData.reviewInsights.summary}</p>

        <div className="strengths">
          <h4>Strengths</h4>
          <ul>
            {enrichedData.reviewInsights.strengths.map((strength, index) => (
              <li key={index}>{strength}</li>
            ))}
          </ul>
        </div>
      </section>

      <section className="services">
        <h3>Services</h3>
        <div className="service-list">
          {enrichedData.serviceDetails.primaryServices.map((service, index) => (
            <div key={index} className="service-card">
              <h4>{service.name}</h4>
              <p>{service.description}</p>
              <p className="cost">Estimated Cost: {service.estimatedCost}</p>
            </div>
          ))}
        </div>
      </section>

      <section className="certifications">
        <h3>Certifications</h3>
        <ul>
          {enrichedData.serviceDetails.certifications.map((cert, index) => (
            <li key={index}>{cert}</li>
          ))}
        </ul>
      </section>
    </div>
  );
}

export default BusinessDetails;
```
